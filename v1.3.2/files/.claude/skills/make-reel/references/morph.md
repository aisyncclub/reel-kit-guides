# 이어지는 도형: scenes.py 쓰는 법

**새 편의 본문 그림은 이 방식이 기본이다.** 편 폴더에 `scenes.py` 가 있으면 엔진이 첫 줄(훅 카드 1.4초 뒤)부터 마지막 본문까지 그림을 **도형 하나로 잇는다**.
장면이 바뀌어도 화면이 끊기지 않는다. 도형이 크기 · 모서리 · 색을 바꾸며 다음 모양이 되고, 안의 내용은 살짝 흐려졌다 또렷해지며 바뀐다.
`scenes.py` 가 없으면 예전 방식(`frames.py`, `look.md`)으로 만든다.

예시: `examples/meeting-notes/scenes.py` (회의록 편 15장면). 결과 영상 생김새는 `GUIDE.html`.

---

## 1. 한 줄 = 한 모양

```python
scene(프레임, 단어, 부품, top="위 꼬리표", foot=("아래 칩", "칩이 뜨는 단어"))
```

- **그 프레임 음성에서 그 단어가 나올 때** 도형이 이 모양으로 바뀐다. 단어 대신 번호도 된다(0 = 프레임 첫 단어)
- 프레임 1 = 첫 줄(훅). 훅 카드(첫 1.4초)가 빠지면 바로 도형이 이어받는다. **첫 줄에도 장면을 둔다**(안 두면 첫 5초가 빈다)
- 순서대로 쓴다. 다음 장면이 앞 장면보다 빠르면 `build` 가 멈춘다
- 스텝 도트 · 다크 띠는 그대로 `DOTS[5] = dots(3, 0)` · `PROMPT[5] = prompt("이렇게 시켰습니다", "…")`

## 2. 빈 화면 금지 (꼭 지킨다)

1. **모양이 바뀌면 0.3초 안에 화면이 찬다.** 부품은 칸 · 줄 · 카드를 바로 세운다. 말하는 단어는 '나타나게'가 아니라 **채우기 · 체크 · 강조 이동 · 줄 긋기**에 쓴다
2. **도형은 그림 칸을 꽉 채운다.** 카메라가 모양마다 크기를 맞춘다(작은 것은 1.6배까지)
3. **둘레를 채운다.** 모양마다 `top`(무엇을 보는지 한 마디)을 붙이고, 결론이 나는 모양에는 `foot`(결과 한 마디)을 붙인다
4. 한 모양은 1~4초. 4초가 넘으면 그 안에서 단어마다 무언가(체크 · 강조 · 채우기)가 움직여야 한다
5. 9줄 기준 장면 12~16개. 줄마다 1~2개

## 3. 부품

| 부품 | 화면에서 | 단어가 하는 일 | 이럴 때 |
|---|---|---|---|
| `doc("제목", lines=12, cross="단어")` | 줄이 빼곡한 문서 | `cross` 에 빨간 가위표가 두 획으로 그어지고, 닿는 순간 화면이 1.1초 흔들린다(#024) | 긴 글 · 메모 · 보고서, "이건 버린다" |
| `typing("친 말", at="단어", reply=8)` | 입력창에 말을 친다 | `at` 에 치기 시작. `reply` 줄이 0.3초마다 자란다 | "클로드에게 시켰더니", 오래 걸린다 · 길어진다 |
| `chips(["말", …], strike="단어", title="제목")` | 큰 알약 줄 | `strike` 에 줄이 그어지고 흐려진다 | 버리는 용어 · 잘못 알던 것 |
| `slots(["?", …], fill="단어", done=False, label=("글", "단어"))` | 세로 칸(점선) | `fill` 에 칸이 하나씩 채워지며 체크 둘레가 튄다(#003). `done=True` 면 처음부터 채워진 칸. `label` 단어에 빛 띠가 칸을 지나간다(#022) | "세 칸", 빈칸 → 완성 |
| `columns([("이름", "설명"), …], picks=["단어", …])` | 나란한 카드 2~4장 | 단어마다 강조 상자가 그 카드로 미끄러진다 | "결정, 할 일, 질문" 차례로 짚기 |
| `badge(번호, "이름", of=3)` | 어두운 단계 카드(큰 번호 · 단계 줄) | — | 스텝 시작 "먼저 결정" |
| `checklist("제목", ["줄", …], fill="단어", count=("3줄", "단어"))` | 목록 카드 | `fill` 에 체크가 하나씩 켜지며 둘레가 튄다(#003) | 뽑힌 결과 몇 줄 |
| `table(["머리", …], [(칸, …), …], picks=[…], fill="단어")` | 표. 머리는 세그먼트 단추 | 단어마다 커서가 머리를 누르고 단추가 미끄러진다. `fill` 에 회색 칸이 글로 채워진다 | "누가 · 언제 · 무엇을 표로" |
| `gather(["알약", …], "상자 이름", pull="단어")` | 위 알약 + 아래 상자 | `pull` 에 알약이 상자 안으로 모인다 | 모은다 · 따로 둔다 · 넣는다 |
| `number(값, "단위", "설명", count="단어")` | 큰 숫자 | `count` 에 0 에서 그 수까지 달려 올라가 멈추고 강조색으로 살짝 튄다(#007). 아래 막대가 찬다 | 확인한 숫자 하나 |
| `compare(("이름", "설명", 비율), ("이름", "설명", 비율), verdict="단어")` | 나란히 비교 + 막대 | `verdict` 에 막대가 차오른다 | 전 · 후, A vs B |

- 부품 안 글은 짧게: 알약 · 칸 10자, 줄 14자 안쪽
- **화면에 쓸 숫자는 확인한 것만.** `number` 는 출처가 있는 숫자에만 쓴다. 비율 막대(`compare`)는 "어림" 이라고 대사에서 말하지 않으면 쓰지 않는다
- 표 · 목록 안 예시 내용은 "예시" 꼬리표를 단다(`top="결정 · 예시"` 처럼)

## 4. 이야기 짜는 법

- 편 전체에 **비유 하나**(예: 「세 칸」). 첫 모양과 마지막 모양이 그 비유의 전과 후다(긴 문서 → 세 칸)
- 같은 부품이 이어지면 도형 크기만 바뀌고 속은 그대로라 심심하다. **다른 부품으로 이어 간다**(문서 → 알약 → 칸 → 카드 → 단계 → 목록 …)
- 스텝 프레임은 `badge` 로 열고(1초 남짓) 그 스텝의 결과 부품으로 넘어간다

## 5. 효과음

**움직임이 소리를 낸다.** `scenes.py` 를 쓰면 엔진이 도형의 움직임마다 효과음을 알아서 붙인다. 소리는 그 움직임과 **같은 단어**에 난다.

| 움직임 | 소리 | 크기 |
|---|---|---|
| 모양이 다른 부품으로 바뀜(문서 → 칸) | `whoosh` 휙 | 작게 0.26 |
| 같은 부품끼리 바뀜(문서 → 문서) | `pop` 톡 | 작게 0.20 |
| 가위표가 닿음(`doc(cross=)`) | `impact` 쿵 | 크게 0.42 |
| 체크 · 칸이 하나씩 켜짐(`checklist(fill=)` · `slots`) | `tick` 똑 (줄마다) | 작게 0.22 |
| 빛 띠가 지나감(`slots(label=)`) | `chime` 띵 | 작게 0.24 |
| 커서가 누름(`table(picks=)`) | `click` 딸깍 | 0.50 |
| 상자로 모임(`gather`) | `whoosh` | 0.30 |
| 큰 숫자가 멈춤(`number`) | `chime` | 0.30 |
| 입력 시작(`typing`) | `click` | 0.40 |

첫 화면 훅 카드가 빠질 때와 마지막 화면 자료 카드 · 키워드 알약 · 커서 클릭 소리는 엔진이 따로 넣는다.

**지킬 것**
- 큰 소리(0.30 넘게)는 한 편에 8개 이하. 화면이 크게 바뀌는 자리에만. 넘으면 `build` 가 알린다
- 같은 자리에 소리가 겹치면 엔진이 뒤 소리를 조금 민다(뭉개지지 않게). 그래서 체크가 셋이면 똑 · 똑 · 똑 으로 난다
- 목소리보다 크게 하지 않는다. 대사 단어에 붙는 소리는 짧은 것(`tick` · `pop` · `click`)만
- 효과음은 키트가 직접 합성한다(외부 음원 없음 · 저작권 걱정 없음): `whoosh` `pop` `impact` `click` `tick` `chime` `thud`

**바꾸는 법**
- 자동 효과음 끄기: `scenes.py` 맨 위에 `SFX = False`
- 내가 정한 자리에만: `episode.json` 에 `"sfx"` 목록을 쓰면 자동 대신 그것만 쓴다
  ```json
  "sfx": [
    {"frame": 4, "word": 3, "sound": "whoosh", "vol": 0.3, "why": "카드 셋이 선다"},
    {"frame": 8, "word": 1, "off": 0.38, "sound": "impact", "vol": 0.42, "why": "가위표"}
  ]
  ```
  `word` 는 그 프레임 단어 번호(0부터), `off` 는 그 단어에서 몇 초 뒤
- 사용자가 "효과음 줄여 줘" → 작은 소리(`tick` · `pop`)부터 빼고, "효과음 빼 줘" → `SFX = False`

## 6. 고칠 때

| 사용자가 말하면 | 하는 일 |
|---|---|
| "5번 그림 다시" | `scenes.py` 에서 5번 프레임 줄만 다시 → `build` → `check` → `snapshot` · `board` |
| "여기 너무 비어 보여" | 그 모양에 `top` · `foot` 을 붙이거나, 더 큰 부품(목록 · 표 · 카드)으로 바꾼다 |
| "더 빨리 바뀌게" | 그 줄을 단어 두 개 장면으로 나눈다 |
| "효과음 빼 줘" · "효과음 줄여 줘" | §5 대로 `SFX = False` 또는 `episode.json` 의 `"sfx"` 로 고른 것만 → `build` |

괄호 속 #번호는 Motion Prompt 카탈로그(MIT)에서 값을 그대로 옮긴 움직임이다(`engine/morph/morph.js`).

검사(`check`)가 글자 대비 · 겹침을 잰다. 스틸(`snapshot`)로 모양이 바뀌는 순간과 다 선 순간을 눈으로 본다.
