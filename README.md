# reel-kit-guides

「클로드 코드 릴스 제작 키트」의 지침 저장소예요. 키트를 시작할 때마다 `python3 engine/reel.py sync` 가 여기서 최신 지침을 받아요.

- 들어 있는 것: 제작 순서(FLOW.md) · 참고 문서(references) · 예시 편 · 사용설명서
- 영상 엔진은 여기 없어요. 엔진은 싱크마켓에서 산 파일에만 들어 있어서, 지침만으로는 영상이 나오지 않아요
- 모든 지침은 판매자 열쇠로 서명돼 있고, 키트가 서명을 확인한 뒤에만 받아요
- 지침을 고쳐 다시 내놓거나 팔 수 없어요

키트 구매: https://aisyncclub.com/market
