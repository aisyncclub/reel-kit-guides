# 화면 규칙과 frames.py 쓰는 법

훅(첫 화면)과 마지막 화면은 엔진이 `episode.json` 으로 만든다. **Claude 가 그리는 것은 본문 프레임(02 ~ 마지막 앞)뿐이고, 그건 `frames.py` 에 쓴다.**
다 쓴 예시: `examples/meeting-notes/frames.py`.

---

## 1. 캔버스 (1080 × 1920) · 배치 두 가지

**화면에 대사를 다시 쓰지 않는다.** 말은 자막이 하고, 위쪽은 그림만으로 설명한다(제목 줄이 없다).
`brand.json` 의 `mascot.bottom` 으로 배치가 정해진다. **그림 캔버스 높이가 다르다**: frames.py 안에서 `CH`(700 · 1000)와 `FULL`(캐릭터 없음이면 True)로 읽는다.
생김새는 `examples/layouts.webp`(왼쪽 캐릭터 없음 · 오른쪽 캐릭터 있음).

```
캐릭터 없음 (기본): 화면 전체 모션그래픽        아래 캐릭터 있음 (mascot.bottom: true)
y 96    진행 도트 (스텝 프레임만)                y 64    진행 도트
y 170 ┐ 그림 CH=1000 (화면 y = SVG y + 170)      y 140 ┐ 그림 CH=700 (화면 y = SVG y + 140)
y 1170┘                                          y 840 ┘
y 1186  다크 띠(prompt)                          y 852   다크 띠(prompt)
y 1310  자막 띠                                  y 1000  자막 띠
                                                 y 1320  캐릭터 (자막 아래에서 시작해 화면 아래 끝에서 잘린다, 말할 때 들썩인다)
y 1594  ★ 이 아래는 인스타 화면이 덮는다          (캐릭터 아래쪽은 덮여도 된다)
y 1846  서명                                     (서명은 캐릭터가 대신한다)
```

- **캐릭터 없음이면 그림이 주인공이다.** 1000 높이를 다 쓴다: 카드를 키우고, 줄 사이를 넓히고, 큰 숫자 · 큰 도형 하나로 화면을 채운다. 700 용 그림을 위쪽에만 두면 아래가 휑하다
- 두 배치 모두에서 쓸 그림이면 예시 편처럼 700 기준 좌표를 `Y(v) = v * CH / 700` 으로 늘린다(`examples/meeting-notes/frames.py` 맨 위)
- 캐릭터를 켜고 끄면 캔버스 높이가 바뀌므로 그 편의 `frames.py` 를 다시 맞춘다

**안전 영역: SVG 안에서 x 40~1040 · y 30~CH-40**(캐릭터 있음 660 · 없음 960). 그림이 프레임 내내 아주 천천히 1.8% 커지기 때문에 가장자리에 닿은 것은 잘린다. `python3 engine/reel.py check <편>` 이 프레임마다 내용 범위를 숫자로 보여 준다.
**검사가 재는 것은 rect · circle · line · text · polyline 과 path 의 시작점뿐이다.** 곡선 · transform · 도형끼리 닿는 것은 못 잰다. 스틸로 눈으로 본다.
**아래를 비워 두지 않는다.** 그림이 캔버스 절반에서 끝나면 휑하다. CH-40 근처까지 채운다.

## 2. 색과 글자

색은 `brand.json` 의 `colors` 에서 온다. **강조색은 하나뿐**이다.
배경은 `background` 로 고른다: `white`(흰색, 기본) · `dark`(어두운색). 어두운색이면 `INK` · `GRAY` · `FAINT` · `CARD` 가 엔진에서 밝은 쪽으로 바뀐다.
**그래서 frames.py 에 색 코드를 직접 쓰지 않는다.** 이름(`INK` · `CARD` …)만 쓰면 두 배경에서 다 맞는다. 카드 바탕에 `WHITE` 를 쓰면 어두운 배경에서 글자가 사라진다.

| 이름 (frames.py) | 쓰임 |
|---|---|
| `ACC` | 강조. 한 화면에 한두 군데만 |
| `INK` | 글자 · 테두리 |
| `GRAY` · `FAINT` | 보조 글자 · 흐린 선 |
| `RED` · `GREEN` | 틀림 · 맞음 표시. 작게만 |
| `CARD` · `PAPER` · `TINT` | 카드 바탕 · 배경 · 강조색 옅은 바탕 |
| `WHITE` | 강조색 위 글자처럼 늘 흰색이어야 하는 곳만 |

- **금지:** 네온 빛 번짐, 큰 그림자, 보라 그라디언트. 강조는 단색 · 밑줄 · 옅은 바탕으로만
- 다크 색은 다크 띠(그 화면을 나오게 한 말)에만 쓴다
- 글자는 Pretendard(본문) · IBM Plex Mono(숫자 · 코드) 두 벌. 키트에 들어 있다
- **한 화면에 큰 글자는 하나.** 둘이 같이 크면 둘 다 안 읽힌다

## 3. 본문은 그림이 설명한다 (eli5)

아무것도 모르는 사람이 소리를 끄고 봐도 무슨 얘기인지 알게 그린다.

1. **글보다 그림이 크다.** 대사 문장을 화면에 쓰지 않는다(자막이 한다). 글자는 그림 속 **2~7자 라벨**만
2. **한 화면에 그림 하나.** 그 줄이 말하는 것 하나만 크게(SVG 폭 가득)
3. **아이콘 · 화살표 · 상자로 단순하게.** 사진 · 복잡한 장면은 쓰지 않는다
4. **어려운 말은 일상 비유 그림으로.** 용어 대신 그 용어가 하는 일을 사물로 그린다(예: 단축키 = 지름길 화살표, 요약 = 깔때기)
5. **확실하지 않은 것은 그리지 않는다.** 숫자는 출처가 있을 때만

| 말로 하던 것 | 그림으로 |
|---|---|
| "한 번도 안 열어 봤어요" | 감은 눈 `eyeoff` + "안 열어봄" |
| "1분이면 끝나요" | 도넛 게이지 `gauge` + "1분" |
| "여기까지만 담겨요" | 비율 막대 `bar(…, 0.6, label="3/5")` |
| "이건 되고 이건 안 돼요" | `check` / `cross` 두 아이콘을 나란히 |
| "할 일을 표로 받아요" | 실제 표 모양 카드 세 줄 |

- **비유는 편 전체에 하나.** 03에서 세우고 다음 프레임들이 같은 도형을 이어받는다
- **추상어를 큰 글자로 다시 쓰지 않는다.** 음성이 "형식"이라고 하면 화면엔 그 형식의 실물(예시 줄 · 표)을 띄운다
- 실제 명령 · 경로 · 프롬프트는 그림이 아니라 **다크 띠**에 한 줄로. 그림이 개념, 띠가 실물이다
- 예시 내용(가짜 이름 · 날짜)을 쓰면 라벨에 "예시"를 붙인다

## 4. frames.py 쓰는 법

엔진이 이 파일을 실행해서 프레임 번호별 딕셔너리를 읽는다. 번호는 정수(2, 3, …)다.

```python
DOTS[5] = dots(3, 0)                     # 진행 도트 3개 중 첫째 켜짐 (스텝 프레임만)
PROMPT[5] = prompt("이렇게 시켰습니다", "회의에서 *정해진 것만* 한 줄씩 뽑아 줘")
ART[5] = masked("c5box", 150, 140, 780, 420, card(150, 140, 780, 420, stroke=INK) + T(540, 360, "결정", INK, 64, "800"))
JS[5] = f'''
  wipeY("c5box", {at(5, "정해진")}, 140, 420, 0.55);
'''
ALT[5] = "결정 카드가 아래에서 쓸려 올라온다"   # 그림 설명 (접근성)
```

### 시점: 초를 박지 않는다

| 쓰는 것 | 뜻 |
|---|---|
| `cue(f, i, off=0)` | 프레임 f 의 i번째 단어(0부터)가 시작하는 시각 |
| `at(f, "단어", off=0)` | 프레임 f 에서 그 단어가 시작하는 시각. 같은 단어 → 들어 있는 단어 순으로 찾는다 |
| `D[f]` | 프레임 길이(초) |
| `WORDS[f]` | 단어 목록과 시각. 단어 번호를 셀 때 본다 |

- 그림은 **그 그림을 말하는 단어**에 건다. 문장 첫 단어에 걸면 말보다 한참 먼저 뜬다
- `cue` · `at` 은 프레임 끝 0.8초 안으로 넘어가지 않게 자동으로 당긴다(끝에 걸린 큐는 안 보인다)
- `JS[f]` 는 f-문자열이라 중괄호를 겹쳐 쓴다: `tl.to(q("#x"), {{opacity:0.3, duration:0.4}}, {cue(3, 3)});`

### 장면에 맞는 움직임 고르기

**움직임은 대사가 하는 말을 보고 고른다.** 장면마다 아래 표에서 하나(많아야 둘)를 고르고, 그 말을 하는 단어에 건다.
같은 움직임이 세 화면 넘게 이어지면 지루하다. 9줄 중 본문 7화면에 **적어도 네 가지**를 섞는다.

| 대사가 이런 말이면 | 움직임 | 예시 편 |
|---|---|---|
| "이걸 보세요" · 하나를 꺼내 보인다 · 결과 한 줄 | `pop` | 02 "또 읽어야 해요" 태그 |
| "N가지" · "세 칸" · 놓는다 · 정한다 | `land` (여러 개면 하나씩) | 03 · 04 · 08 |
| 목록 · 표 · 막대가 쌓인다 · "한 줄씩" | `rise` (+ 줄마다 `pop` 체크) | 05 · 06 |
| "첫째, 둘째" · "A, B, C" 차례로 짚는다 | `hilite` + `slide` | 04 |
| 고른다 · 누른다 · 시킨다 · "이걸 누르면" | `tap` (+ `slide`) | 06 |
| "여기만 보면" · 한 곳을 자세히 | `focus` (1.08~1.15) | 02 |
| 모은다 · 넣는다 · 정리한다 | `tl.to` 로 상자 안으로 이동(`ease:sp(12,7,0.7)`) | 07 |
| 버린다 · 필요 없다 · 틀렸다 | `draw` 로 줄 긋기 + 흐리게(`opacity:0.3`) · `cross` 에 `pop` | 03 · 08 |
| 바뀐다 · 전 → 후 | `wipeY` 로 앞 것 · 화살표 `fade` · 뒤 것 `wipeY` | 02 |
| 숫자 · 점수 · 비율 | `countUp` · `meter` | |

**표에 맞는 게 없으면** Motion Prompt 카탈로그에서 찾아 옮긴다(`references/motion-catalog.md`). 예: 휙 넘기기, 뒤집기, 타자 치기, 지도 위 점 잇기.



`brand.json` 의 `tone.motion` 이 `calm` 이면 같은 함수가 넘침 없이 미끄러지듯 선다(튀어나옴은 살짝 커지며 나타남, 떨어짐은 찌그러짐 없이). frames.py 는 그대로 둔다.

**말하는 대로 화면이 움직여야 직관적이다.** 단어가 나올 때 그 물건이 떨어지고, 지금 말하는 쪽으로 강조 상자가 옮겨 가고, "표로"라고 하면 커서가 눌러 표가 선다.
움직임 값은 Motion Prompt 카탈로그(MIT)에서 옮겼다. 숫자는 그대로 두고 쓴다.

| 함수 | 하는 일 | 언제 | 원본 |
|---|---|---|---|
| `pop("#id", 시점, dy)` | 0에서 1.26배까지 부풀었다 서고, 살짝 돌며 들어온다(0.82초). 선택자가 여럿이면 다 같이 | 배지 · 태그 · 알약 · 체크 | #001 |
| `land("선택자", 시점)` | 위에서 떨어져 바닥에 닿는 순간 납작했다 돌아온다. 여럿이면 0.12초씩 늦게(0.9초) | 카드 · 칸을 "놓을" 때 | #011 |
| `rise("선택자", 시점)` | 바닥에 붙어 솟는다(0.5초, 0.12초 간격) | 목록 줄 · 막대 · 표의 행 | #002 |
| `slide("id", 시점, x, y, w, h)` | `hilite()` 로 그린 강조 상자가 그 자리로 미끄러진다. 앞 변이 먼저 가서 늘어났다 줄어든다(0.36초) | "결정, 할 일, 질문" 처럼 차례로 짚을 때 | #060 |
| `tap("#id", 시점, x, y)` | 커서가 (x, y) 로 날아와 누르고 물결이 퍼진다. 누른 것은 살짝 눌린다 | 고르기 · 시키기 · "이걸 누르면" | #085 |
| `focus(시점, x, y, 배율)` | 카메라가 (x, y) 로 밀고 들어간다(0.9초). `focus(시점)` 은 제자리로 | 한 군데를 크게 보여 줄 때. 1.08~1.15 | 카메라 |
| `meter("선택자", 시점)` | 선 · 게이지가 목표를 25% 넘었다 돌아온다(1.1초) | 게이지 · 점수 | #010 |
| `wipeX` · `wipeY("gid", 시점, …)` | `masked` 로 감싼 그림을 연다 | 긴 문서 · 상자 | |
| `fade("#id", 시점)` · `draw("선택자", 시점, 길이)` | 서서히 나타남 · 선을 그려 나감 | 화살표 · 지우는 선 | #004 |
| `countUp("#id", 시점, 시작, 끝, 길이, "개")` | 숫자 카운트업 | | #007 |
| `tl.to(q("#id"), {{…}}, 시점)` | 그 밖의 움직임. 스프링은 `ease:sp(12,7,0.7)` | 카드를 상자 안으로 모으기 등 | |

- **한 화면에 움직임은 두세 가지.** 넷을 넘으면 산만하다. 한 번에 하나만 움직이고, 움직인 뒤에는 잠깐 선다
- `focus` 로 밀고 들어간 동안에는 `tap` 을 쓰지 않는다(커서는 카메라를 따라가지 않는다)
- 강조 상자는 그림보다 **먼저** 그린다(`ART[f] = hilite(...) + 카드들`). 그래야 카드 뒤에 깔린다

**같은 요소를 이어서 움직일 때는 앞 움직임이 끝난 뒤에 건다**(pop 0.82 · land 0.9 · rise 0.5 · fade 0.34 · 와이프는 준 길이). 겹치면 검사가 `overlapping_gsap_tweens` 로 잡는다.

**와이프는 `masked` 로 감싼 그룹에만 걸린다.** `masked(gid, x, y, w, h, 안쪽)` 의 사각형이 안쪽 그림보다 작으면 그림이 **영구히** 잘린다.

### 도형 함수 (ART 안에서)

| 함수 | 모양 |
|---|---|
| `T(x, y, 글, 색=GRAY, 크기=32, 굵기="500", a="middle", fam="Pretendard Variable", extra="")` | 글자. `a` 는 start · middle · end, 숫자 · 코드는 `fam="IBM Plex Mono"`, `extra` 는 태그에 붙일 속성 |
| `card(x, y, w, h, stroke, fill, r, sw, dash)` | 둥근 카드 |
| `pill(cx, cy, 글, fill, color, s)` | 알약 라벨 |
| `arrow(x1, y1, x2, y2)` | 화살표 |
| `check(x, y, s=1.0)` · `cross(x, y, s=26)` | 체크(s 는 배율) · 가위표(s 는 반 크기 px) |
| `gauge(cx, cy, r, "id")` | 도넛 게이지 (`draw("#id", …)` 로 돌린다) |
| `bar(x, y, w, h, 비율, label="3/5")` | 비율 막대 |
| `doc(x, y, s)` · `bubble(x, y, s)` · `person(x, y, s)` | 문서 · 말풍선 · 사람 |
| `eyeoff(x, y, s)` · `lock(x, y, s, open_=True)` | 감은 눈 · 자물쇠 |
| `hilite("id", x, y, w, h, r)` | 강조 상자(옅은 강조색 + 테두리). `slide` 로 옮긴다 |

필요한 모양이 없으면 frames.py 안에 함수를 새로 만든다(예시 편의 `memo` · `slots`). SVG 문자열을 돌려주면 된다.

### 글자 상자가 겹칠 때

일부러 겹친 글자(카드 위에 숫자를 얹는 것 등)는 검사가 `content_overlap` 에러로 잡는다. **겹치는 글자 태그마다** 속성을 붙인다(부모 `<g>` 에 붙이면 안 먹는다):

```python
T(540, 300, "215", ACC, 60, "800", extra="data-layout-allow-overlap")
```

일부러가 아니면 간격을 다시 잡는다.

글자 상자는 대략 **위로 글자 크기의 1.03배, 아래로 0.27배**다. 큰 숫자 아래 설명을 둘 때는
`다음 baseline ≥ 앞 baseline + 앞 크기 × 0.27 + 뒤 크기 × 1.03 + 여유` 로 잡는다.

## 5. 모션 문법

| 쓰는 것 | 언제 |
|---|---|
| 스프링(`pop` · `land` · `slide` · `sp(w,d,길이)`) | 기본. 목표를 살짝 넘었다 돌아와 앉는 쫀득한 맛 |
| `power3.out` · `power4.out` | 와이프 · 서서히 나타남 |
| `power3.in` | 나가는 것 |

**금지:** 통통 튀는 반복 바운스, `yoyo`, `repeat`, `Math.random()`, `Date.now()`, CSS `transition`, 네트워크 요청. 렌더할 때마다 다른 영상이 나온다.
프레임 진입(그림 · 띠가 한 덩어리로 밀려 올라옴)과 미세 확대는 엔진이 이미 넣는다.

## 6. 훅과 마지막 화면 (엔진이 만든다)

| 화면 | 바꾸는 곳 |
|---|---|
| 훅 카드 문구 · 마스트헤드 | `episode.json` 의 `hook` |
| 훅 뒤 절반에 서는 그림 두 장 | 본문 장면 그림(`frames.py` 의 ART). 기본은 3번과 마지막 앞 장면, 바꾸려면 `episode.json` 의 `hero_frames`(예: `[4, 8]`) |
| 마지막 화면 꼴 | `episode.json` 의 `cta`: `save`(저장 · 팔로우, 카드에 제목 + `recap` 세 줄) · `keyword`(댓글에 ○○, 카드에 `kit` 의 이름 · 구성 3줄 · 키워드 알약. 자료 만들기 추가 기능이 있을 때) |
| 마감 문구 | `brand.json` 의 `cta.tagline` |
| 마스코트 | `brand/mascot/hook.png` · `cta.png` |

이 두 화면을 손으로 고치고 싶으면 `engine/lib/hookcta.py` 를 고친다. 생성된 HTML 을 고치면 다음 `build` 에서 날아간다.
