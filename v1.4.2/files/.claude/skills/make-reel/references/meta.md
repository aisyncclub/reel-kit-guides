# 올릴 때 쓰는 글: 캡션 · 고정 댓글 · 대체 텍스트 · DM · 쇼츠

영상이 나온 뒤 `episodes/<편>/out/` 에 텍스트 파일로 만든다. **올리는 건 사용자가 직접 한다.**

| 파일 | 무엇 | 한도 · 주의 |
|---|---|---|
| `caption.txt` | 인스타 캡션 | 줄바꿈까지 세서 **350자 안쪽**. 해시태그 8개 이하. **할 일(CTA)은 하나** |
| `pinned-comment.txt` | 고정 댓글 | (keyword) 자료 이름 + 받는 법 한 줄 · (save) 저장 · 팔로우 유도 한 줄 |
| `dm.txt` | 댓글 키워드에 자동으로 보낼 DM | **keyword 꼴만.** 자료 링크 + 짧은 인사 (자동 발송은 쓰는 서비스에서 사용자가 직접 설정). save 꼴이면 만들지 않는다 |
| `alt-text.txt` | 대체 텍스트 | 화면에 실제로 있는 것만. 프레임 수만큼 |
| `shorts.txt` | 유튜브 쇼츠 제목 · 설명 · 고정 댓글 | **사용자가 쇼츠판을 달라고 할 때만.** 제목에 검색어. 고정 댓글에 자료 링크 |

---

## 1. 캡션 꼴

```
댓글에 '[키워드]' 남겨 주시면
[자료 이름] 보내 드릴게요.

[문제]인 건
[통념]이 아니라
[진짜 원인]이라서인데,
[해결책]만 하면
[구체적 이득]해요!

💛[가장 센 숫자 하나]
([출처])

다만 [범위를 좁히는 문장].
[이유]거든요.

[자료 내용]은 자료에 담았는데,
여기 다 적기엔 너무 길어요😥

💬필요하신 분은 편하게 댓글 남겨 주세요!

✔️ 도움 됐다면 '좋아요'
✔️ [언제 다시 볼지] '저장'
✔️ [brand.json 의 cta.tagline 그대로, {handle} 포함]

#태그 #태그
```

- **첫 줄 키워드는 영상 마지막 화면의 알약과 같은 단어다.** 다르면 사람들이 다른 말을 남기고 자동 DM 이 안 걸린다
- **save 꼴(`"cta": "save"`)이면** 첫 두 줄을 "[언제] 다시 보게 저장해 두세요." 한 줄로 바꾸고, "자료에 담았는데 / 너무 길어요😥 / 💬댓글" 세 줄을 빼고 그 자리에 `recap` 세 줄을 ✔️ 없이 적는다. 키워드 · DM 말은 쓰지 않는다
- 숫자 줄(💛)은 **실측 숫자만**. 없으면 그 두 줄을 빼고 위아래 빈 줄 하나만 남긴다
- 경험 문장은 **사용자가 실제로 겪은 것만.** 채울 수 없으면 비워 두고 묻는다
- 넘치면 숫자 둘째 줄 → 출처 괄호 → 공유 줄 순으로 뺀다
- 생성 이미지를 썼으면 해시태그 위에 "사진은 AI 생성이에요." 한 줄
- 금지어(게임체인저 · 혁명적 · 무조건 · 떡상 · 대박 · 미쳤다)를 쓰지 않는다

## 2. 고정 댓글 · DM

```
[고정 댓글]
📎 [자료 이름] · 댓글에 '[키워드]' 남겨 주시면 DM 으로 보내 드려요.

[DM]
안녕하세요! 말씀하신 [자료 이름] 보내 드려요 🙌
👉 [자료 링크]
도움 됐다면 {handle} 팔로우도 부탁드려요.
```

**save 꼴이면 DM 은 없고 고정 댓글은 저장 · 팔로우를 시킨다:**

```
[고정 댓글 · save]
📌 [언제] 다시 보게 저장해 두세요. 이런 정리가 더 필요하면 {handle} 팔로우!
```

keyword 꼴에서 링크를 아직 모르면 `[자료 링크]` 자리표시자를 두고, 링크가 생기면 채운다. **올리기 전에 자리표시자가 남았는지 확인한다**:

```bash
grep -n '\[자료 링크\]\|\[링크\]' episodes/<편>/out/*.txt    # 아무것도 안 나와야 한다
```

## 3. 대체 텍스트

프레임마다 한 줄. `frames.py` 의 `ALT` 를 다듬어 쓰면 된다. 화면에 없는 말을 보태지 않는다.

## 4. 유튜브 쇼츠

- 제목: 검색어가 앞에. 40자 안쪽
- 설명: 첫 두 줄에 핵심 + 자료 받는 곳("고정 댓글에 있어요")
- 고정 댓글: 자료 링크
- 영상은 마지막 줄만 바꾼 쇼츠판(`script.md` §1-2)을 쓴다. 인스타판의 "댓글에 키워드"는 쇼츠에서 통하지 않는다

## 5. 올리기 전 점검

- [ ] `out/reel.mp4` 1080×1920 · 40~55초 (`render` 가 출력한 값)
- [ ] `out/cover.png` 를 릴스 커버로 골랐다
- [ ] (keyword) 캡션 첫 줄 키워드 == 영상 알약 키워드 == DM 자동 응답 키워드
- [ ] (keyword) 자료 이름이 영상 · 캡션 · 고정 댓글 · DM 에서 같다
- [ ] (save) 캡션 · 고정 댓글에 "댓글에 ○○" · 자료 얘기가 없다
- [ ] 화면 · 캡션의 숫자마다 출처나 세는 법이 있다
- [ ] 자리표시자(`[ ]`)가 하나도 없다
- [ ] 남의 로고 · 캐릭터 · 고유 문구가 화면에 없다
